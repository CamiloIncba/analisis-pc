# Análisis de hardware para PC gaming en Chile (octubre 2026)

Página: https://camiloincba.github.io/analisis-pc/

Cuatro configuraciones (entrada, media, alta y estado del arte) con precios reales de tiendas chilenas (SoloTodo,
11 de octubre de 2026) y rendimiento medido juego por juego por Juan Isaacs (Zona Technosensual).

- `index.html`: la página publicada (se genera desde `propuesta.json`).
- `analisis.md`: el análisis completo en texto, con las mismas tablas y el camino de actualización de cada pack.
